# Agentic AI Research Paper Intelligence System

An AI-powered system designed to intelligently process, analyze, and query research papers using large language models and agentic workflows.

## Overview

This project utilizes advanced NLP libraries and frameworks such as:
- Hugging Face `transformers` and `datasets`
- `sentence-transformers` for embeddings
- `langchain` and `langgraph` for agentic workflows and LLM orchestration
- `keybert` for keyword extraction

## Setup

The main code is provided in the Jupyter Notebook `Agentic_AI_Research_Paper_Intelligence.ipynb`.

1. Open the notebook in Jupyter or Google Colab.
2. Run the initial cells to install the required dependencies.
3. Follow the notebook instructions to execute the intelligence system.

## Requirements
- Python 3.9+
- Jupyter Notebook / JupyterLab
